# Dogear logo assets

The wordmark spells the pronunciation, `dɔgɪr` (dog-ear). The product name is always written **Dogear** in text; file names use `dogear-*`.

Lead (ear): `#5960B3`  
Ink (body): `#161827`

These are the Bilberry Apricot palette's Lead and Ink swatches (`extension/theme.js`). The ear stays Lead on both light and dark backgrounds.

## Files

- `dogear-lockup-primary.svg`: primary horizontal mark + `dɔgɪr` wordmark for light backgrounds.
- `dogear-mark-primary.svg`: symbol only for light backgrounds.
- `*-reversed.svg`: for dark backgrounds; white body with the same Lead ear.
- `*-black.svg` / `*-white.svg`: one-color applications.
- `dogear-mark-{size}.png`: square icon exports from 16 to 1024 px.
- `dogear-lockup-{width}w.png`: horizontal lockup exports from 320 to 2560 px wide.

## Usage

- **16–24 px:** symbol only. Use for browser favicon, compact browser toolbar, or tiny status UI. If details soften at 16 px, prefer the black one-color mark.
- **32–64 px:** symbol only. Use for browser-extension icons, app navigation, avatars, and small UI buttons.
- **128–256 px:** symbol only or lockup. Use for app listings, social profiles, loading screens, and product cards.
- **512–1024 px:** symbol only. Use for app-store artwork, social profile masters, and high-density screens.
- **320–640 px lockup:** website headers, login screens, documentation headers, and email signatures.
- **1280–2560 px lockup:** presentations, press materials, print, and high-resolution exports.

Use the lockup when the audience may not already know the brand: landing pages, launch posts, presentations, documentation, and first-run product screens. Use the symbol alone after the name has already been established: favicons, extension toolbar icons, app navigation, avatars, and repeated UI placements.

Keep clear space around the mark equal to at least the height of the ear-shaped lobe. Do not recolor individual pieces, stretch the artwork, rotate it, add shadows, or place the primary version on a dark or visually busy background.
